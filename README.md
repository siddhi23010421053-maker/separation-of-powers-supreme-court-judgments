# Separation of Powers in the Supreme Court of India

This project presents issue and ruling summaries for 19 Supreme Court of India cases concerning separation of powers, institutional boundaries, judicial review, and judicial restraint, together with the course dataset workbook and CSV export.

## Contents

- `index.html` — responsive, searchable issue/ruling table
- `data.xlsx` — the course dataset template, completed with the available case summaries
- `data.csv` — CSV export of the Data sheet
- `chart1-per-year.svg`, `chart2-outcome.svg`, `chart3-who-won.svg` — visual summaries of the dataset
- `scripts/make_charts.py` — regenerates the charts with `python scripts/make_charts.py`
- `separation-of-powers-report.pdf` — a formatted report with the project overview and 19 case summaries

## Scope

The project presents a curated set of Supreme Court cases on separation of powers, institutional boundaries, judicial review, and judicial restraint. State of Jharkhand v. Harihar Mishra is omitted in accordance with the project instructions.

## Limits

This is a hand-picked summary list, not a comprehensive search of all Supreme Court decisions on separation of powers. The dataset workbook retains the course template’s fields and structure.
