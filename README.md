# Separation of Powers in the Supreme Court of India

This simplified project summarizes issue and ruling notes for 19 Supreme Court of India cases concerning separation of powers, institutional boundaries, judicial review, and judicial restraint.

## Contents

- `index.html` — responsive, searchable issue/ruling table
- `cases.csv` — the same summaries in CSV format
- `case-summary.xlsx` — the same summaries in a simple workbook
- `separation-of-powers-report.pdf` — a formatted report with the project overview and 19 case summaries

## Scope

The project presents a curated set of Supreme Court cases on separation of powers, institutional boundaries, judicial review, and judicial restraint. State of Jharkhand v. Harihar Mishra is omitted in accordance with the project instructions.

## Limits

This is a hand-picked summary list, not a comprehensive search of all Supreme Court decisions on separation of powers. The workbook contains only the case, year, issue, and ruling; it does not include the full coding fields, evidence quotes, charts, or doctrinal trend analysis from the original assignment specification.
